# Política de seguridad

## Versiones soportadas

La rama `main` y la última release `0.7.x` reciben correcciones de seguridad. Las versiones anteriores pueden
quedar sin soporte cuando la versión publicada avanza.

## Reporte privado

No abras un issue público para una vulnerabilidad. Usa el reporte privado de GitHub:

<https://github.com/wilkin-barban/Trindade/security/advisories/new>

También puedes escribir a <barbanwilkin@gmail.com>. Incluye:

- Versión web o Android y build (`versionName`/`versionCode`) afectados.
- Plataforma y pasos de reproducción.
- Impacto observado y evidencia sanitizada.

No incluyas credenciales, tokens, datos de producción, el keystore de firma ni APKs firmados en un reporte
público.

## Alcance

Aplican el backend/API, el frontend web, la aplicación Android, el despliegue Docker y la integración con el ERP
Aero32.

## Divulgación

Confirma el reporte antes de divulgar detalles. Se dará crédito a quien lo solicite y se coordinará una ventana
razonable de corrección.
